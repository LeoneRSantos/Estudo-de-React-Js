# Projeto base para o estudo do framework React com Vite

- Este repositório contem uma aplicação frontend simples usado para estudos.
- Objetivos:
  - [] Construir um sistema simples para gerenciamento de usuários.
  - [] Construir um modal para cadastro de usuários.
  - [] Construir uma página para listar os usuários cadastrados.
  - [] Possibilitar a edição dos dados de um usuário.
  - [] Possibilitar a remoção de um usuário.
